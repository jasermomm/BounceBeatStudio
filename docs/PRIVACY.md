# Privacy

BounceBeat Studio is local-first.

## Data it stores

- project files you explicitly save
- autosave recovery data
- recent project and MIDI paths
- application settings and shortcuts
- window layout
- local diagnostic logs
- temporary rendering files while exporting

## Network behavior

The application does not contain telemetry, analytics, advertising, account login, cloud sync, paid APIs, or an update tracker. It does not upload MIDI, projects, audio, or video.

Package installation and optional system package managers may access the internet independently. FFmpeg and FluidSynth are local executables once installed.

## Logs

Logs may contain local file paths and technical errors. Review logs before attaching them to a public issue. The repository and bundled demo assets contain no personal names, email addresses, user-directory paths, secrets, or machine-specific configuration.

## Project sharing

A `.bouncebeat` project can contain embedded MIDI. Confirm that you have permission to redistribute embedded music and any SoundFont-derived output.
