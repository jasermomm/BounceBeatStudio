# Settings and shortcuts

## Application settings

Settings are stored with Qt platform settings under the application name. They include:

- FFmpeg path
- SoundFont path
- theme
- autosave enabled and interval
- master volume
- sample rate
- buffer size
- audio device label
- latency
- customized shortcuts
- recent files
- window geometry and dock layout

## Default shortcuts

| Action | Shortcut |
|---|---|
| Play or pause | Space |
| Restart | R |
| Record/render dialog | Ctrl+R |
| Save | Ctrl+S |
| Save as | Ctrl+Shift+S |
| Open project | Ctrl+O |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Delete selected | Delete |
| Duplicate selected | Ctrl+D |
| Fullscreen preview | F11 |
| Step one frame | Right Arrow |
| Fit entire canvas | Ctrl+0 |
| Actual pixels | Ctrl+1 |
| Zoom in/out | Standard platform zoom shortcuts |
| Exit fullscreen/cancel active view action | Escape |

Copy, paste, and new-project commands use standard platform shortcuts. Most application shortcuts can be changed in **Tools → Settings**.

## Preview navigation

- Mouse wheel: editor zoom
- Middle drag: pan
- Alt + left drag: pan
- Left click: select
- Left drag on an unlocked object: move

Editor navigation never changes the project camera unless a camera property is edited directly.
