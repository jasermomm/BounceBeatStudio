# Support

Use GitHub Discussions when enabled for setup questions, workflow help, and general usage. Use an issue for reproducible bugs or focused feature requests.

Before reporting a bug:

1. Read `docs/TROUBLESHOOTING.md`.
2. Reproduce with the latest version.
3. Run `python -m pytest` and `python scripts/validate_release.py` when working from source.
4. Include the operating system, Python version, application version, selected preset, physics settings, and whether Pymunk, FluidSynth, and FFmpeg are active.
5. Remove personal paths, MIDI, project assets, and secrets from logs before posting them publicly.

Do not attach copyrighted MIDI or SoundFonts unless you have permission to share them.
